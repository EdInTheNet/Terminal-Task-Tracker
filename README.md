# TERMINAL TASK-TRACKER 

## Description
The Terminal Task-Tracker ist a Terminal based application that allowes the User to add multiple tasks with a description and a state, the User can then decide when he whants to complete the task what state it has and if it is complette.

## Controles 
-add -> will ask the user to give a task a title and a description and will add it to the task listist
-show all -> will show all saved taskeds 
-change -> will change the state of the task from one of the tree (OPEN, IN_PROGRESS, CLOSED)
-delete -> will delete a task based on the Titel of it
